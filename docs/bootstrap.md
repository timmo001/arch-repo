# Bootstrap

1. Enable R2 in the Cloudflare dashboard and configure a budget alert.
2. Create the dedicated offline certification key and restricted signing subkey.
3. Export the public key to `keys/timmo-arch-repo.asc` and its full primary fingerprint to `keys/FINGERPRINT`.
4. Add the encrypted signing-subkey export and passphrase to the protected GitHub `production` environment.
5. Create least-privilege Cloudflare credentials for R2 publication, domain provisioning, and exact cache purges.
6. Run `pnpm provision:check`, then explicitly run `pnpm provision:apply`.
7. Build the initial empty database with `pnpm bootstrap` and publish it through the protected workflow.
8. Run `pnpm health` and install from a clean Arch environment.

R2 activation, credentials, and private signing material are manual security ceremonies. They are not generated by repository scripts.
